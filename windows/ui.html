Подключение iPhone по Bluetooth

Без «Связи с телефоном» — программа подключается к iPhone сама
  1. На iPhone включите Bluetooth, разблокируйте экран и положите телефон рядом с компьютером.
  2. Нажмите «🔎 Найти iPhone рядом» — сопрягать в настройках Windows не нужно. (Если iPhone уже сопряжён в Windows, можно выбрать его в списке.)
  3. На iPhone появится «Запрос на создание пары» — нажмите «Создать пару».
  4. Не нашёлся? Нажмите «📡 Показать ПК в Bluetooth iPhone», затем на iPhone: Настройки → Bluetooth → внизу «Другие устройства» → нажмите на имя компьютера.
  5. Сразу после этого — запрос «Разрешить … получать уведомления?» → «Разрешить». Программа ждёт до 3 минут. Если запроса нет: Настройки → Bluetooth → (i) у компьютера → включите «Показывать уведомления».
Нажмите «Обновить список»,
чтобы найти сопряжённый iPhone
Сопряжённого iPhone нет? Нажмите «Настройки Bluetooth» и добавьте его. Если на компьютере нет Bluetooth — подойдёт любой USB-адаптер Bluetooth 5.0.

    Хоткеи на донаты

    Как работает

    При донате на нужную сумму программа нажимает сочетание клавиш — например, включает эффект или сцену в TikTok Live Studio. Сочетания настраиваются в кабинете на сайте, здесь они появляются сами. Кнопка «Проверить» нажмёт сочетание через 1,5 секунды — успейте переключиться в нужное окно.
