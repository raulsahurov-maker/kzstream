🛡 Почему браузер или Windows может предупредить и как установить

Программа безопасна: она только читает уведомления о переводах и отправляет их на ваш аккаунт KZStream. Предупреждение появляется у любой новой программы без платного сертификата Microsoft — оно исчезнет, когда программу скачает больше людей.

  1. Скачайте ZIP-архив — браузеры обычно не блокируют архивы. Откройте его и запустите KZStream-Setup.exe.
  2. Если Chrome пишет «Подозрительный файл» — нажмите на загрузку → «Сохранить» (или «Всё равно скачать»). В Edge: «…» → «Сохранить» → «Показать больше» → «Всё равно сохранить».
  3. Если Windows показывает синее окно «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
  4. Установка займёт несколько секунд, программа запустится сама.
