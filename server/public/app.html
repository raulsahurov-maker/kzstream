Подключение телефона или ПК

Ваша ссылка подключения

В приложения Android и Windows просто войдите своим email и паролем. Ссылка нужна для iPhone («Команды»). Никому её не показывайте.

  1. Скачайте приложение KZStream для Android на странице «Скачать» и установите APK.
  2. Откройте приложение и войдите тем же email и паролем, что на сайте.
  3. Нажмите «Дать доступ к уведомлениям» и включите KZStream в списке.
  4. Нажмите «Отключить экономию батареи» — иначе Android может выгрузить приложение.
  5. Нажмите «Проверить связь». В ленте на главной появится запись.

2. Триггер «Уведомление»

Выберите «Уведомление» → «Приложение» → Kaspi.kz. Включите «Запускать сразу» и выключите «Уведомлять при запуске». Нажмите «Далее» → «Новая пустая автоматизация».

3. Действие «Получить содержимое URL»

В поиске действий введите «URL» → «Получить содержимое URL». В поле URL вставьте:

Раскройте «>» → Метод POST → Тело запроса JSON.

JSON
title → Заголовок
text → Текст
4. Два поля

Нажмите «Добавить новое поле» → Текст два раза:

title→ переменная «Заголовок» (из «Уведомление»)
text→ переменная «Текст» (из «Уведомление»)

Переменные выбираются над клавиатурой после нажатия на поле значения.

5. Сохраните и проверьте

Нажмите «Готово». Попросите друга перевести 100 ₸ с сообщением — алерт появится в эфире, а запись — в журнале ниже.

Совет: в Настройках → Уведомления → Kaspi.kz включите «Допуск уведомлений» и «Показ миниатюр: Всегда».

  1. Подключите телефон к ПК через приложение Windows «Связь с телефоном» (Phone Link) и разрешите показ уведомлений Kaspi.
  2. Скачайте KZStream для Windows на странице «Скачать» и запустите.
  3. Войдите своим email и паролем. При первом запуске Windows спросит доступ к уведомлениям — разрешите.
  4. Программа также выполняет ваши хоткеи (тариф Pro) — держите её запущенной во время эфира.

Виджеты для TikTok Live Studio

Как добавить в TikTok Live Studio

Откройте TikTok Live Studio → «Добавить источник» → «Ссылка» (Link) → вставьте ссылку виджета → «Добавить». Растяните виджет на нужное место кадра. Алерты и рулетку лучше растянуть на весь экран, ТОП и цель сбора поставить сбоку. Перед эфиром отправьте тестовый донат на главной.

ТОП донатеров Бесплатно

Конструктор виджета: выберите дизайн, шрифт и размеры — превью меняется сразу. На Free — дизайн «Классика» с небольшим логотипом KZStream.

В превью — примерные донатеры. В эфире будут ваши настоящие донаты.

Хоткеи

Программа KZStream для Windows нажмёт клавиши при донате в диапазоне суммы. Например ctrl+shift+1 — смена сцены в TikTok Live Studio.

Вебхуки

При каждом донате отправляем POST с JSON (имя, сумма, сообщение) на ваши адреса. До 5 штук.
