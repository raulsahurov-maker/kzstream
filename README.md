# KZStream — Kaspi-донаты для стримеров

Полный сервис: сайт + регистрация + личный кабинет + виджеты для OBS + приложения для Android, Windows и iPhone.

```
kzstream/
├── server/      сайт, кабинет, API, виджеты (Node.js 22, SQLite — отдельная БД не нужна)
├── android/     приложение для Android (ловит уведомления Kaspi)
├── windows/     программа для Windows (уведомления через «Связь с телефоном» + хоткеи)
└── .github/     автосборка APK и EXE на GitHub (бесплатно)
```

## Как это работает

1. Зритель открывает страницу стримера `сайт/d/ник`, пишет имя, сумму и сообщение.
2. Сайт показывает номер Kaspi стримера — зритель переводит **ровно эту сумму**.
3. На телефон стримера приходит уведомление Kaspi «Перевод 2 000 ₸ от Аружан А.».
4. Приложение KZStream отправляет текст уведомления на сервер.
5. Сервер находит ожидающий донат с той же суммой (за последние 30 минут) и показывает алерт
   с сообщением в OBS: гифка, звук, озвучка, рулетка, топ, цель — всё обновляется мгновенно.
   Если зритель перевёл без страницы — алерт всё равно будет, с именем из Kaspi.

Сервис **не трогает деньги** — переводы идут напрямую на Kaspi стримера, комиссии нет.

## 1. Запуск сервера

Нужен VPS с публичным адресом (ps.kz, hoster.kz, Timeweb, Hetzner — любой за ~2–5 тыс. ₸/мес)
и домен. Сайт должен работать по **https** — иначе OBS и приложения не подключатся.

### Вариант А — Docker (проще)

```bash
cd server
cp .env.example .env        # впишите свои данные (см. ниже)
docker build -t kzstream .
docker run -d --name kzstream --restart always -p 3000:3000 --env-file .env -v kzstream-data:/data kzstream
```

### Вариант Б — напрямую через Node.js 22.13+

```bash
cd server
npm install --omit=dev
cp .env.example .env
npm start
```
Чтобы сервер не падал после перезагрузки: `npm i -g pm2 && pm2 start npm --name kzstream -- start && pm2 save && pm2 startup`.

### HTTPS (бесплатно, автоматически) — Caddy

```bash
sudo apt install caddy
echo 'kzstream.kz {
  reverse_proxy localhost:3000
}' | sudo tee /etc/caddy/Caddyfile
sudo systemctl reload caddy
```
Домен должен смотреть A-записью на IP сервера. Caddy сам получит сертификат.

### Настройки `.env`

| Параметр | Что это |
|---|---|
| `PUBLIC_URL` | Адрес сайта, напр. `https://kzstream.kz` |
| `PAY_KASPI`, `PAY_NAME`, `PAY_TELEGRAM` | Kaspi для оплаты подписок (по умолчанию +7 775 884 27 91, Алибек Т.) и Telegram для чеков (@raulanrip) |
| `ADMIN_EMAILS` | Email админов. **Первый зарегистрированный пользователь автоматически админ** |
| `APK_URL`, `EXE_URL` | Ссылки на приложения (см. п. 2) |
| `DATA_DIR` | Где хранить базу и файлы (делайте бэкап этой папки) |

## 2. Приложения (сборка на GitHub — бесплатно)

1. Создайте аккаунт на github.com → **New repository** → имя `kzstream` → Create.
2. Загрузите туда всю папку проекта (кнопка «uploading an existing file» или `git push`).
3. Откройте вкладку **Actions** — сборка запустится сама (~5–8 минут).
4. Готовые файлы появятся во вкладке **Releases → latest**: `KZStream.apk` и `KZStream.exe`.
5. Впишите в `.env` сервера:
   ```
   APK_URL=https://github.com/ВАШ_НИК/kzstream/releases/download/latest/KZStream.apk
   EXE_URL=https://github.com/ВАШ_НИК/kzstream/releases/download/latest/KZStream.exe
   ```
   Или просто положите оба файла в `server/downloads/`.

Кнопки на странице `/download` сразу начнут скачивать приложения.

**Android:** APK подписан отладочным ключом — при установке Android попросит разрешить «Установку из неизвестных источников».
Для Google Play нужен свой ключ подписи.

**Windows:** при первом запуске SmartScreen может предупредить «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
Убрать предупреждение можно покупкой сертификата подписи кода.

**iPhone:** приложение не нужно — работает через автоматизацию «Команды» (инструкция в кабинете → «Подключение»).
Для App Store нужен Mac и аккаунт разработчика Apple ($99/год).

## 3. Админка и оплата подписок

- Откройте `сайт/admin` (видна только админам).
- Стример выбирает тариф в кабинете → переводит деньги на ваш Kaspi → жмёт «Я оплатил».
- Вы видите заявку в админке, проверяете перевод в Kaspi → **«Подтвердить»** → тариф включается на 30 дней × месяцев.
- Там же можно вручную выдать любой тариф любому пользователю.
- VIP: после 10 оплаченных месяцев стример автоматически получает +10 дней Pro и ×1.5 хранилища.

## Виджеты OBS

`/w/alerts.html`, `top`, `goal`, `roulette` (5 стилей: колесо, слоты, карточки, мистери-бокс, CS Case),
`media` (YouTube), `info`, `timer` (сабатон). Ссылки с токеном — в кабинете → «Виджеты».
Тем оформления 10 × виджеты = 30+ дизайнов.

## Важно знать

- **Формат уведомлений Kaspi.** Распознаются варианты вида «Перевод 2 000 ₸ от Имя Ф.», «Вам перевели…»,
  «Пополнение…», «Поступление…», а также Halyk и другие банки. Если Kaspi поменяет текст — в кабинете →
  «Подключение» видно, что пришло, а правила разбора лежат в `server/lib/parse.js`.
- **Совпадение по сумме.** Если два зрителя одновременно переведут одинаковую сумму, сообщения могут
  перепутаться местами. Ожидающий донат можно подтвердить вручную в кабинете → «Донаты».
- **Озвучка** идёт через Google Translate TTS; если он недоступен — через встроенный голос браузера.
- Сервис не аффилирован с АО «Kaspi Bank» — дисклеймер уже есть на сайте.

## Проверка без телефона

В кабинете → «Главная» → «Тестовый донат», или запросом:
```bash
curl -X POST https://ваш-сайт/api/ingest/ТОКЕН -H "Content-Type: application/json" \
  -d '{"title":"Kaspi.kz","text":"Перевод 1 000 ₸ от Тест Т."}'
```
